# Contributing

Contributions are welcome if they improve clarity, reproducibility, or analytical depth.

## Development Setup

```bash
pip install -r requirements.txt
pytest -q
streamlit run app.py
```

## Guidelines

- Keep analysis reproducible and avoid hardcoded local paths.
- Add tests when changing data processing or modeling logic.
- Keep visualizations clear and portfolio-ready.
- Document new methodology or findings in `docs/` or `reports/`.
