# Power BI Dashboard Plan

## Objective

Create an executive-style dashboard for YouTube trending video performance in India.

## Pages

1. Overview
   - Total trending videos
   - Average views
   - Average engagement rate
   - Unique channels

2. Category Performance
   - Trending videos by category
   - Average views by category
   - Engagement rate by category

3. Publishing Behavior
   - Publish hour vs engagement
   - Publish day vs engagement
   - Top publishing windows

4. Channel Analysis
   - Top channels by trending count
   - Average views by channel
   - Engagement by channel

5. Engagement Quality
   - Like ratio
   - Comment ratio
   - High engagement flag

## Recommended Filters

- Category
- Year
- Publish day
- Channel title
- High engagement flag
