# Findings

- Trending count is concentrated in a few high-volume categories.
- Views show a long-tail distribution, meaning most videos receive moderate views while a few go extremely viral.
- Engagement ratios give a fairer comparison than raw likes or raw comments.
- Upload hour and upload day provide useful behavioral context but should not be treated as causal without additional data.
- Random Forest feature importance shows that engagement ratios and audience response metrics are strongest for classifying high-engagement trending videos.

## Limitation

This project does not predict whether a brand-new video will become trending. A true trending prediction model would require both trending and non-trending videos, plus early upload metrics or pre-publication metadata.
